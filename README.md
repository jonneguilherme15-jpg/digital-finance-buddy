# FinPay: Smart Wallet

Claro! Se você vai usar em uma ferramenta de criação de apps por IA, como Base44, Lovable ou similar, pode usar este prompt:

Prompt — App de Fintech

Crie um aplicativo de fintech moderno, profissional e intuitivo chamado "FinPay".

O aplicativo deve funcionar como uma carteira digital e plataforma de controle financeiro pessoal, com uma interface semelhante a bancos digitais modernos.

TELA INICIAL:
- Mostrar saldo disponível em destaque.
- Botões rápidos: Pix, Transferir, Pagar, Depositar e Sacar.
- Exibir últimas transações.
- Mostrar resumo financeiro do mês.
- Card com entradas e saídas.
- Permitir ocultar/exibir o saldo.

PIX:
- Enviar Pix usando chave CPF, telefone, e-mail ou chave aleatória.
- Área para inserir valor e descrição.
- Tela de confirmação antes de concluir.
- Histórico de Pix enviados e recebidos.
- QR Code para receber pagamentos.

CARTÕES:
- Mostrar cartão virtual.
- Mostrar limite disponível.
- Mostrar limite utilizado.
- Botão para bloquear/desbloquear cartão.
- Opção de gerar cartão virtual.
- Lista de compras realizadas com o cartão.

CONTROLE FINANCEIRO:
- Gráficos simples mostrando receitas e despesas.
- Categorizar gastos em alimentação, transporte, lazer, compras, contas e outros.
- Filtro por período.
- Mostrar quanto o usuário gastou no mês.
- Criar metas de economia.

PAGAMENTOS:
- Pagamento de boletos.
- Área para inserir ou escanear código de barras.
- Histórico de pagamentos.

INVESTIMENTOS:
- Área com investimentos.
- Mostrar saldo investido e rendimento.
- Criar opções como CDB, fundos e renda fixa.
- Mostrar informações de forma simples para usuários iniciantes.

NOTIFICAÇÕES:
- Avisar sobre Pix recebido.
- Avisar sobre pagamentos realizados.
- Avisar sobre compras no cartão.
- Alertar quando o limite estiver próximo do máximo.

PERFIL E SEGURANÇA:
- Dados pessoais.
- Alteração de senha.
- Biometria.
- Autenticação em duas etapas.
- Gerenciamento de dispositivos conectados.
- Central de ajuda e suporte.

DESIGN:
- Interface limpa e moderna.
- Estilo de banco digital.
- Cores principais azul-escuro, branco e detalhes em verde.
- Ícones minimalistas.
- Cards com cantos arredondados.
- Navegação inferior com: Início, Pix, Cartões, Finanças e Perfil.
- Responsivo para celular.
- Criar estados de carregamento, telas vazias, mensagens de erro e confirmações de sucesso.

IMPORTANTE:
O aplicativo é um protótipo/demo de fintech. Não realizar transações financeiras reais. Utilizar dados fictícios e uma arquitetura preparada para futura integração com APIs bancárias.
